How this page works. There is no server. The interpreter is
  lambda_calculus_interpreter.py from the root of this repository; the page fetches
  that exact file and runs it on CPython compiled to WebAssembly
  (Pyodide). Nothing about the interpreter was
  changed to make this work — web/bridge.py is a thin adapter that
  drives the same tokenize → parse → compile → evaluate pipeline and hands
  the results back as data instead of writing them to disk.
